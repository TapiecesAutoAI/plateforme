# 12 — CODING STANDARDS

**Version :** 1.0

---

## Règles

- Un fichier = une responsabilité.
- Aucun code mort.
- Build obligatoire après chaque modification.
- Tests avant validation.
- Aucun `any` sans justification.
- Types centralisés.
- Nommage cohérent.
- Moteur indépendant de l'interface.
- Toute règle métier appartient aux Knowledge Packs.
- Chaque changement doit être documenté.
