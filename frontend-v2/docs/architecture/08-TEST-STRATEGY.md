# TaPiecesAuto AI

# 08 — TEST STRATEGY

**Version :** 1.0
**Statut :** Spécification officielle

---

# 1. Objectif

Garantir qu'une évolution n'introduit aucune régression.

---

# 2. Types de tests

- Unitaires
- Intégration
- End-to-End
- Knowledge Packs
- Régression

---

# 3. Règles

Chaque nouvelle fonctionnalité possède au moins un test.

Chaque bug corrigé possède un test.

---

# 4. Validation

Avant chaque livraison :

- build
- tests
- validation fonctionnelle

---

# 5. Régression

Les anciens scénarios doivent toujours produire le même résultat.

---

# 6. Règle absolue

Aucune modification n'est validée sans tests.
