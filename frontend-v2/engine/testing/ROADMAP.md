# PLAN DE VALIDATION DU MOTEUR EXPERT

Objectif final :
- 500 scénarios de référence.
- 95 % de diagnostics corrects.
- < 7 questions pour un particulier.
- < 10 questions pour un mécanicien.

Répartition :

STARTING
---------
001-050 Batterie
051-090 Démarreur
091-120 Alternateur
121-150 Antidémarrage
151-180 Masse / cosses
181-200 Carburant

CHARGING
---------
201-240

IGNITION
---------
241-280

FUEL
---------
281-330

ENGINE
---------
331-400

COOLING
---------
401-430

BRAKING
---------
431-460

STEERING
---------
461-480

SUSPENSION
---------
481-500

Chaque scénario devra mesurer :

- nombre de questions
- temps de résolution
- hypothèse finale
- confiance finale
- deuxième hypothèse
- pièce proposée
- questions inutiles
- contradictions rencontrées
- score de réussite

Le moteur ne sera considéré comme validé que lorsqu'il passera les 500 scénarios sans régression.
